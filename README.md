## ✨ Overview

This filter combines targeted cosmetic CSS rules to hide modal overlays with procedural scriptlets to defuse enforcement scripts without breaking standard video player controls.

* **Clean Suppression:** Removes modal backdrops, dialogs, and video blockages.
* **Zero Bloat:** Minimalist rules focused exclusively on anti-adblock scripts.
* **Universal Compatibility:** Should works on every Chromium and Firefox-based adblock engines.
